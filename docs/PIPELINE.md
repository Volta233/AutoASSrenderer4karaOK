# 固定制作流程

上传视频并确认元信息 → 导入或联网选择歌词并确认 → Kim 人声 → 双遍短窗口 ASR → TIFA 窗口定位 → 歌词匹配和小于 90 秒的分块 → TIFA 正式对齐与局部重试 → 标记式补齐 → 时间轴检查 → 导出。

Qwen3-ASR 用于确定音频中实际唱了什么，TIFA 用于获得词的时间。确认歌词才是最终字幕原文，ASR 不直接替换原文。全曲没有 Qwen ForcedAligner，也没有两个 FA 融合步骤。

人声只服务识别，原 MV 的背景音乐和人声一起保留在最终成片。推理缺词不阻止字幕输出；文件缺失、CUDA 不可用、人声长度变化、无法安全分块等运行错误仍会明确报告，不能伪装为高精度输出。

每句都有输出不等于每句时间准确。带估算标记的部分、重复副歌、间奏衔接和 ASR 识别较差的部分应优先检查。
