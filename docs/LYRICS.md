# 搜索、确认与处理歌词

普通查词不需要 API Key，不调用 AI。第二步输入歌名，可选填写实际演唱歌手。不同歌手、翻唱、录音室、现场及短版歌词可能不同，采用前请试听核对。

## 来源顺序与失败回退

1. **LRCLIB**：先查原歌名和歌手；候选不理想时取消歌手过滤，再尝试最多三个去重的繁简/日文字形标题。例如“千本樱 → 千本櫻 → 千本桜”。名称转换只用于查询和比较，不修改歌词。
2. **网易云音乐**：前一来源失败、无歌词，或缺少名称和时长合适的候选时，查询公开歌曲目录，再读取最多三个候选的原文 LRC。翻译和罗马音伴随轨不混入原文。无需登录、Cookie 或 Key；公开接口可能变化或限流。
3. **指定歌词网站**：先搜索 UtaTen 的歌名目录，读取最多三个歌词正文；仍缺少合适版本时，在 UtaTen 与 J-Lyric 范围内搜索，再读取最多三个受支持的歌词页面。只解析明确的歌词区域；注音、罗马音副本、广告和搜索摘要不当作完整歌词。
4. 仍无候选时，通用网页结果只供查看来源和人工核对，或导入 TXT/LRC。遇到登录、验证码、403、503 或不支持的页面结构会记录失败并继续其他来源，不绕过限制。

找到合适的候选后可提前停止，不保证每次都查询所有网站。来源失败时不立即反复重试同一服务。界面折叠的“检索记录”显示实际查询、来源、HTTP 状态、记录数和可用歌词数；不会把没有请求过的网站列成成功来源。

## 怎样理解候选建议

- **建议优先试听**：歌名、歌手名称及来源录音时长相符，未发现时长矛盾；仍需确认实际演唱内容。
- **请确认演唱版本**：未填写歌手。即使同名、时长相近，也无法排除翻唱或不同编曲。
- **需核对差异**：例如歌手名称不同、来源录音时长未知、录音时长有差异，或标题标注翻译/改编。

名称相似度比较文本与明确列出的合作歌手，不会猜测“初音ミク = Hatsune Miku”等别名。内部排序分按歌名、歌手、时长加权，缺少字段时只计算已知证据；它**不是音频匹配率，也不是对齐成功概率**。缺少时长等证据的候选不会因此获得“建议优先试听”。主界面先显示前三个候选，其余折叠；每个候选可展开正文和来源。

来源没有录音时长时明确显示未知。来源录音时长与 MV 不一致时提示版本复核，不使用歌词时间标签判断版本，不自动缩放到视频内。语言检测只作提示，不证明音轨语言。没有提供实际 ASR/试听证据时，不会声称某句已唱过或已确认整曲完整。

## 歌词处理边界

搜索取得歌词、导入 TXT/LRC 和保存粘贴文本都经过同一清洗函数。去掉明确的 LRC 元数据、段落标记、逐句/逐字时间标签和署名行，再展示候选或保存。保留歌词正文和来源，用显示文本之外的规范化文本进行对齐。来源时间直接丢弃，不保留为提示，不按它排序，也不用它判断版本；MV 字词时间由识别和对齐流程生成。旧记录中的来源时间字段在读取时忽略。

“自动识别”会参考整份歌词判断纯汉字句的语言：日语假名占明显多数时，纯汉字句随日语上下文处理；英文行保留英文。明确选择中文、日语或英语时尊重该选择。自动判断仍可能出错，混合语言或合成歌声建议先在第一步明确演唱语言。

保留原文行顺序及明确写出的重复副歌、重复句，不按文本去重。同一行的多个时间标签只删除，不据此复制或重排歌词；压缩式 LRC 的重复副歌需要在确认歌词时按实际演唱展开。UtaTen 页面只读取原文区域，排除假名注音及隐藏罗马音副本；疑似混入译文或罗马音时给出复核提示，不猜测删除。完整版与剪辑版的取舍由用户确认，缺词时间仍明确标为估算。

检索结果由用户确认，不调用 LLM 校正。匹配建议来自歌名、歌手和来源时长等可检查的证据；实际演唱版本仍需核对，选错版本时可以重新选取或手动编辑。
