映词 · LyriFrame Kim

安装与启动

1. 把整个压缩包解压到电脑硬盘，不要在压缩包里直接运行。
2. 准备 Python 3.10–3.14（常规 64 位 CPython）和 NVIDIA 显卡驱动。安装程序会自动查找可用版本。
3. 双击 install.cmd，自动优先从国内镜像下载并安装。等到显示 Installation complete。
4. 双击 start.cmd，浏览器自动打开。

制作流程

选择视频 → 确认歌词 → 歌词同步 → 导出视频。
可以导入、粘贴歌词，也可以联网查找，不需要 API Key。
成片默认命名为“歌名 - 歌手_KTV.mp4”，可在时间轴播放视频检查字幕。

本包不含模型。首次下载模型等资源约 6 GB，加上运行环境建议预留 40 GB 磁盘。
运行需要 NVIDIA 显卡。处理流程为 Kim 人声分离、ASR 片段识别、TIFA 逐字对齐。

维护与迁移

Kim 和 ASR 默认优先通过魔搭下载。网络波动会自动重试，最多每来源重试 10 次。
网络中断后再次运行 install.cmd，不用从头解压。
以后使用直接双击 start.cmd。关闭浏览器不会停止后台处理。
双击 stop.cmd 停止程序及模型子进程，也可以关闭启动窗口退出。
未完成任务会中断，已保存的数据保留。
迁移时在目标电脑重新运行 install.cmd；已有制作任务请单独备份 ktv_projects 目录。
完整说明见 README.md。运行 check.cmd 可生成环境检查报告。
